# Demo buildings

Buildings made with the plan upload (Level 4) that we keep for the demo. Install them with
`scripts/install_demo_buildings.sh`; the page then lists them as `user/<id>`.

## plan-89323a15: Munich Urban Colab (Freddie-Mercury-Straße 5, 80797 München)
- Source: photos of the evacuation plans on site (K33 Brandschutz, 26.03.2021): ground floor E.05, 1st floor OG1.06.
  Each plan shows only part of its floor.
- Read by the plan reader, then doors added by hand (the plans draw no door widths), voids (Luftraum) set to outdoor.
- Scale: 47 m building width, checked against the official room sizes (munich-urban-colab.de/en/event-spaces):
  Project Room 142 m² (official 141), Foyer 309 m² (281, with auditorium 330), Seminar Rooms 1-3 316 m² (323).
- Room names: official names where the website has them (Foyer, Auditorium (Arena), Project Room, Seminar Rooms 1-3,
  Café (Gastraum)), otherwise the plan's names.
- Known gaps: no assets (fire extinguishers and call points are on the plans but not read), 2 entrances only,
  floors 2 to 4 and the basement not included.
